## 结局如何决定（已由游戏代码确认）

1. **候选资格。** 只看 55 个普通结局（`EndingType = 2`）。**每个条件组至少要有一条成立**才是候选（组内“或”、组间“且”）。
2. **计分。** 分数 = `Weight` + 加成，只保留分数最高的，**同分随机抽一个**。
3. **加成。** `Weight` ≥ 30000 的结局没有加成；低于 30000 的加成 = `min(2 × 相关课程／打工累计次数, 8000)`，实际只有几百。它能让 Weight 相近的结局重新排序，但不会跨越 Weight 的档次。
4. **例子。** 女王 52000、魔王 51000、公主 50000；大富豪、魔法剑士、外交官都是 40000 且没有加成，全部达成时随机抽一个。

评价阶级：1 = 0、2 = 50、3 = 150、4 = 250、5 = 350、6 = 500。课程／打工等级：3 = B、4 = A、5 = S。

## 恋人结局如何决定

结婚对象按以下顺序决定：

1. 已经接受求婚而设定的伙伴（8 位种族伙伴）直接沿用。
2. 否则依次判断：凯姆（Episode1 完成且结局为餐厅店员）、艾科萨（Episode1 且魔法教习）、奇马里斯（Episode1 且士兵）、穆扎伊（Episode1 且作家）、吉普（`Cube_Episode2` 完成）、单身（12 项基础能力值总和 ≥ 3600，没有恋人结局）、“平凡的幸福”（结局为无业或村民）。
3. 都不符合则保持默认对象（默认也是“平凡的幸福”）。

求婚固定在 1218 年 3 月月初、伙伴最后一段剧情完成后发生，只有选“接受”才会设定对象。魔王与公主互斥，公主结局需要魔族男（阿加雷斯）的求婚标记。

## 占卜师如何提示

占卜师最多提示 3 个结局。进度是各条件组最佳进度按分数加权后的平均；显示门槛会在 2920 天内由 20% 升到 80%。`Ending_Jobless` 与 `Weight` < 1000 的结局不会被提示。

## 与吉普（Cube）的关系

状态编号 21（`RelationshipCube`，范围 −100 到 500）。**每排一格“家务”（`Job_House`）行程，就在行程开始时增加该格的天数**，与成功或失败无关。每月前两格各 10 天，最后一格为（当月天数 − 20）天。三段 `E_Job_House` 事件各再 +1。`Cube_Episode1` 需要 ≥ 70、`Cube_Episode2` 需要 ≥ 120，大约需要 7 格与 12 格的家务行程。游戏内名称（例如“与吉普的关系”）取自游戏的 `Text` 表。

## 尚缺的部分

- `Flow_Vacance`（度假事件）与王城遇人地点 703～708 的场景名称尚未解析。
