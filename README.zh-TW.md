## 結局怎麼決定（已由遊戲程式碼確認）

1. **候選資格。** 只看 55 個一般結局（`EndingType = 2`）。**每個條件組至少要有一條成立**才是候選（組內「或」、組間「且」）。
2. **計分。** 分數 = `Weight` + 加成，只留分數最高的，**同分隨機抽一個**。
3. **加成。** `Weight` ≥ 30000 的結局沒有加成；低於 30000 的加成 = `min(2 × 相關課程／打工累積次數, 8000)`，實務上只有數百。它能讓 Weight 相近的結局重新排序，但不會跨越 Weight 的檔次。
4. **例子。** 女王 52000、魔王 51000、公主 50000；大富豪、魔法劍士、外交官都是 40000 且沒有加成，全部達成時隨機抽一個。

評價階級：1 = 0、2 = 50、3 = 150、4 = 250、5 = 350、6 = 500。課程／打工等級：3 = B、4 = A、5 = S。

## 戀人結局怎麼決定

結婚對象依以下順序決定：

1. 已經接受求婚而設定的夥伴（8 位種族夥伴）直接沿用。
2. 否則依序判斷：凱姆（Episode1 完成且結局為餐廳店員）、艾科薩（Episode1 且魔法教習）、奇馬里斯（Episode1 且士兵）、穆扎伊（Episode1 且作家）、吉普（`Cube_Episode2` 完成）、單身（12 項基礎能力值總和 ≥ 3600，沒有戀人結局）、「平凡的幸福」（結局為無業或村民）。
3. 都不符合就維持預設對象（預設也是「平凡的幸福」）。

求婚固定在 1218 年 3 月月初、夥伴最後一段劇情完成後發生，只有選「接受」才會設定對象。魔王與公主互斥，公主結局需要魔族男（阿加雷斯）的求婚旗標。

## 占卜師怎麼提示

占卜師最多提示 3 個結局。進度是各條件組最佳進度依分數加權後的平均；顯示門檻會在 2920 天內由 20% 升到 80%。`Ending_Jobless` 與 `Weight` < 1000 的結局不會被提示。

## 與吉普（Cube）的關係

狀態代號 21（`RelationshipCube`，範圍 −100 到 500）。**每排一格「家務」（`Job_House`）行程，就在行程開始時增加該格的天數**，與成功或失敗無關。每月前兩格各 10 天，最後一格為（當月天數 − 20）天。三段 `E_Job_House` 事件各再 +1。`Cube_Episode1` 要 ≥ 70、`Cube_Episode2` 要 ≥ 120，大約需要 7 格與 12 格的家務行程。遊戲內名稱（例如「與吉普的關係」）取自遊戲的 `Text` 表。
