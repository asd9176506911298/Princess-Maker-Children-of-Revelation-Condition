## エンディングの決まり方（ゲームコードで確認済み）

1. **候補。** 通常エンディング 55 個（`EndingType = 2`）のみが対象です。**すべての条件グループで少なくとも 1 つ満たしている**ものが候補になります（グループ内は OR、グループ間は AND）。
2. **スコア。** スコア = `Weight` + ボーナス。最高スコアのものだけが残り、**同点はランダム**で 1 つ選ばれます。
3. **ボーナス。** `Weight` が 30000 以上のエンディングにはボーナスがありません。30000 未満では `min(2 × 関連する授業／仕事の累積回数, 8000)` で、実際には数百程度です。Weight が近いもの同士の順位は入れ替わりますが、Weight の段階を飛び越えることはありません。
4. **例。** 女王 52000、魔王 51000、プリンセス 50000。大富豪・魔法剣士・外交官はいずれも 40000 でボーナスなしのため、全部満たすとランダムで 1 つになります。

評価ランク：1 = 0、2 = 50、3 = 150、4 = 250、5 = 350、6 = 500。授業／仕事のランク：3 = B、4 = A、5 = S。

## 恋人エンディングの決まり方

結婚相手は次の順で決まります。

1. 求婚を受けて設定済みのパートナー（8 人の種族パートナー）はそのまま使われます。
2. そうでなければ順に判定します：カイム（Episode1 クリア済みでエンディングがレストラン店員）、イコサ（Episode1 かつ魔法師範）、キマリス（Episode1 かつ兵士）、ムザイ（Episode1 かつ作家）、キューブ（`Cube_Episode2` クリア済み）、独身（基礎能力 12 項目の合計 ≥ 3600、恋人エンディングなし）、「ありふれた幸せ」（エンディングが無職または村人）。
3. どれにも当てはまらなければ既定の相手のままです（既定も「ありふれた幸せ」）。

求婚は 1218 年 3 月の月初、パートナーの最後のストーリーを終えた後に発生し、「受ける」を選んだ場合のみ相手が設定されます。魔王とプリンセスは両立しません。プリンセスエンディングには魔族男（アガレス）の求婚フラグが必要です。

## 占い師のヒント

占い師は最大 3 つのエンディングを示します。進捗は各条件グループの最良の進捗をスコアで重み付けした平均で、表示のしきい値は 2920 日かけて 20% から 80% に上がります。`Ending_Jobless` と `Weight` が 1000 未満のものは示されません。

## キューブとの関係

ステータス番号 21（`RelationshipCube`、範囲 −100〜500）。**「家事」（`Job_House`）のスケジュールを 1 枠入れるたび、開始時にその枠の日数分だけ増えます**（結果の成否は無関係）。毎月の最初の 2 枠は 10 日、最後の枠は（その月の日数 − 20）日です。`E_Job_House` の 3 つのイベントがそれぞれ +1 します。`Cube_Episode1` は ≥ 70、`Cube_Episode2` は ≥ 120 が必要で、家事のスケジュールはおよそ 7 枠・12 枠必要です。ゲーム内の名称（「キューブとの関係」など）はゲームの `Text` テーブルによるものです。
